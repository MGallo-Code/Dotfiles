# Dev Process & Design

## Dev Process
- Build from ground-up, refine after. Get something working fast, expect 5-10 rounds of tweaks.
- Commit at natural checkpoints.
- When he says "you take the reins" - make a decision and commit to it, don't hedge. But course-correct if issues arise.


## Editor
- Uses Neovim (LazyVim) as primary editor. Repo: MGallo-Code/NVIM-Setup.git.
- Config path: macOS/Linux `~/.config/nvim/`, Windows `%LOCALAPPDATA%\nvim\` (i.e. `C:\Users\moses\AppData\Local\nvim\`).

## Infrastructure
- Wants to learn infrastructure, not just have it done. Walk through what needs to happen and why.
