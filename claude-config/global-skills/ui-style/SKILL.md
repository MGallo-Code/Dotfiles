# UI style

The always-on rules (`~/.claude/rules/ui-style.md`) apply to every UI. Open each topic file below whose trigger matches the work, before building:

- `core.md` (APP-): building or changing any app with more than one screen.
- `components.md` (COMP-): building or changing a component: forms, lists, tables, dialogs, menus, pickers, editors, media.
- `touch.md` (TOUCH-): anything that runs on a phone or tablet, or takes touch input.
- `desktop.md` (DESK-): anything used on a desktop or laptop screen.
- `assistant.md` (CHAT-): building a chat or AI-assistant interface.
- `personal-tools.md` (SOLO-): a tool only Michael uses, or a mock or review page for him (never a client product or KeepTheCall).
- `process.md` (PROC-): planning, mocking, reviewing or reporting on UI work with Michael.
- `always.md` (UI-): the always-on rules in full, with why and examples.

Before calling UI work done, walk the change against these rules, wording and labels first (the `ui-review` skill does this).
